# Geometric Lib

`geometric_lib` — библиотека на Python для нахождения периметра и площади разных фигур.

## Решение

Для круга, квадрата, треугольника и прямоуголника написаны отдельные модули с функциями для вычисления периметра и площади

## Функции

### Треугольник

Модуль `geometric_lib.triangle` содержит функции для вычисления площади и периметра треугольника.

#### `area(a, h)`

Вычисляет площадь треугольника по стороне `a` и высоте `h`, опущенной на эту сторону.

**Аргументы:**

- `a` (`float`) — сторона, на которую опущена высота.
- `h` (`float`) — высота треугольника.

**Возвращает:** `float` — площадь треугольника.

```python
from geometric_lib.triangle import area

area(10, 5)
# 25
```

#### `perimeter(a, b, c)`

Вычисляет периметр треугольника по данным длинам трёх сторон.

**Аргументы:**

- `a` (`float`) — длина первой стороны.
- `b` (`float`) — длина второй стороны.
- `c` (`float`) — длина третьей стороны.

**Возвращает:** `float` — периметр треугольника.

```python
from geometric_lib.triangle import perimeter

perimeter(3, 4, 5)
# 12
```

### Круг

Модуль `geometric_lib.circle` содержит функции для вычисления площади круга и длины окружности.

#### `area(r)`

Вычисляет площадь круга по данному радиусу `r`.

**Аргументы:**

- `r` (`float`) — радиус круга.

**Возвращает:** `float` — площадь круга.

```python
from geometric_lib.circle import area

area(5)
# 78.53981633974483
```

#### `perimeter(r)`

Вычисляет длину окружности по радиусу `r`.

**Аргументы:**

- `r` (`float`) — радиус круга.

**Возвращает:** `float` — длина окружности.

```python
from geometric_lib.circle import perimeter

perimeter(5)
# 31.41592653589793
```

### Квадрат

Модуль `geometric_lib.square` содержит функции для вычисления площади и периметра квадрата.

#### `area(a)`

Вычисляет площадь квадрата по данной стороне `a`.

**Аргументы:**

- `a` (`float`) — длина стороны квадрата.

**Возвращает:** `float` — площадь квадрата.

```python
from geometric_lib.square import area

area(2)
# 4
```

#### `perimeter(a)`

Вычисляет периметр квадрата по данной стороне `a`.

**Аргументы:**

- `a` (`float`) — сторона квадрата.

**Возвращает:** `float` — периметр квадрата.

```python
from geometric_lib.square import perimeter

perimeter(2)
# 8
```

### Прямоугольник

**Аргументы:**

**Возвращает:** `float` — площадь прямоугольника.
